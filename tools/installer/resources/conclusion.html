Installation terminée

Au premier lancement de l'application, acceptez l'accès au micro. Dans votre logiciel audio, rescannez les plugins puis cherchez « Von De Larsen ».

Le profil Neural Engine est chargé automatiquement ; le curseur ciseau / cerveau agit alors des deux côtés.

Si macOS bloque l'application (« endommagée ») : dans le Terminal,
xattr -dr com.apple.quarantine "/Applications/Von De Larsen.app"
